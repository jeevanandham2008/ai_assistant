# AI Registration Assistant

## Project Description

AI Registration Assistant is a Python-based virtual assistant designed to help users with course registration.

The assistant can provide information about available courses, registration, eligibility, and registration status.

## Features

- User greeting
- Course information
- Course registration
- Eligibility checking
- Name validation
- Age validation
- Email validation
- Course selection
- Registration summary
- Error handling
- Interactive chatbot conversation

## Available Courses

1. Python
2. Data Science
3. Artificial Intelligence

## Technologies Used

- Python 3.14
- Python IDLE
- Natural Language Processing concepts
- Conditional statements
- Functions
- Loops
- Input validation

## How to Run

1. Install Python 3.x.
2. Download or clone this repository.
3. Open `main.py` using Python IDLE.
4. Press F5 to run the program.
5. Follow the instructions displayed by the assistant.

## How It Works

The user interacts with the assistant through the terminal.

The assistant identifies the user's request and provides an appropriate response.

For registration, the assistant collects:

- Name
- Age
- Email
- Course

The assistant then validates the information and displays the registration status.

## Sample Interaction

User: register

Assistant: What is your name?

User: Jeevan

Assistant: What is your age?

User: 18

Assistant: Enter your email address.

User: example@gmail.com

Assistant: Select a course.

Registration Status: SUCCESSFUL

## Project Objective

The objective of this project is to develop a simple AI-powered registration assistant that can guide users through course registration and provide basic eligibility and course information.
